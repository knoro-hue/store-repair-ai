# APIキーなし版：Gemini の Gem で使う

Webツールを使わず、Gemini に判定基準を登録した「Gem」を作る方法です。
**APIキーもサーバーも不要**です。店舗は Gem のリンクを開いて写真を送るだけです。

## 作り方（本社の担当者が1回だけ・スマホで5分）
スマホで **https://knoro-hue.github.io/store-repair-ai/gem.html** を開き、画面の手順どおりに進めます。
1. 「指示文をコピー」をタップ
2. 「Gemを作成する」をタップ → 名前 `修繕AI判定`、カスタム指示に貼り付けて保存
3. Gemの「共有」からリンクをコピーし、店舗に送る

※Geminiアプリで作成画面が出ない場合は、ブラウザで開いて「PC版サイトを表示」に切り替えてください。

## 店舗への配布
- 共有リンクを店舗のスマホで開く（Geminiアプリが入っていればアプリで開きます）
- ホーム画面にショートカットを追加しておくと、1タップで開けます

## 店舗での使い方
1. Gem を開く
2. 📷 で修繕箇所を撮影（全体1枚＋近接1枚がおすすめ）、一言メモを添えて送信
3. 1行目が「🚨 緊急」なら、表示された「今すぐやること」を実行し、本社に電話
4. AIからの質問に番号で答える
5. 最後に「依頼文」と送ると、本社への依頼文が出るので、コピーしてメール・Teams 等で送る

## 注意
- 判定基準を変えたら、Gem の「カスタム指示」も更新してください（`../criteria.js` と内容を揃える）。
- Gem の共有は、Google Workspace の場合、管理者設定で無効になっていることがあります（要確認）。
- 個人の Google アカウントで使う場合、会話は Gemini アプリのアクティビティ設定によって Google のサービス改善に使われることがあります。気になる場合は「Gemini アプリ アクティビティ」をオフにするか、Workspace アカウントで使ってください。
